## Local Setup

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the wordpress folder into:

   C:\xampp\htdocs\

4. Create a MySQL database named:

   wordpressdb

5. Import the file:

   wordpressdb.sql

6. Create wp-config.php using wp-config-sample.php.
7. Enter your local database details in wp-config.php.
8. Open the website:

   http://localhost/wordpress/

9. To open WordPress Admin:

   http://localhost/wordpress/wp-admin/

## Admin Content Editing

Website content can be edited from the WordPress Admin Dashboard.

Go to:

Dashboard → Pages → Select Page → Edit → Update
